## 游戏简介

你是一名写字楼里的普通打工人，白天对着 Excel，夜里梦回江湖。

《摸鱼江湖》完整复刻经典文字游戏《英雄坛说》的核心设定：**掷骰创角、四维属性、拜师学艺、潜能练功、打工赚钱、野外历练、擂台切磋、集市摆摊、江湖奇遇、声望称号**，并加入多人江湖元素：世界/门派频道、群侠排行榜、玩家摊位经济、江湖快讯播报。

一切设计围绕"摸鱼"两个字：

| 特性 | 说明 |
|---|---|
| 终端伪装 | 黑底绿字命令行风格，远看像在跑脚本、看日志 |
| 老板键 | 按 `` ` `` 一键切换成"项目进度跟踪表.xlsx"，浏览器标题栏同步伪装 |
| 静默原则 | 无声音、无弹窗、无大动画，纯文字 + 小面板 |
| 碎片节奏 | 战斗可自动演算到底；打工/练功挂机结算，切走页面照常累计 |
| 零门槛 | 无需安装，浏览器打开即玩；单文件可离线 |

## 快速开始

1. 用浏览器打开 `index.html`（或访问部署好的在线地址）。
2. 点击 **初来乍到 · 注册**，输入名号与口令。
3. 掷骰生成四维属性（不满意可重掷 **1 次**），点 **就这个了 · 闯江湖**。
4. 按大厅底部命令行提示：输入 `1`~`9` 打开各功能，或直接点左侧菜单。
5. **摸鱼第一课**：按一下键盘 `` ` ``（Tab 上方），体验老板键。

> 存档自动保存在浏览器 localStorage，多账号可随时切换；换电脑请用属性页的 **导出/导入存档**。

## 操作手册

### 键盘快捷键（全屏通用）

| 按键 | 作用 |
|---|---|
| `` ` ``（或 `~`） | **老板键**：一键伪装成 Excel 工作表 / 恢复游戏 |
| `Esc` | 退出老板伪装；从功能页返回大厅 |
| `1` ~ `9` | 大厅内快捷导航（见下表） |
| `Enter` | 发送频道消息 / 执行命令行输入 |

### 大厅菜单与数字键对照

| 键 | 菜单 | 功能 |
|---|---|---|
| `1` | 属性 | 四维属性、装备、背包、物品、武功总览 |
| `2` | 拜师 | 六大门派拜师、学门派武功、门派任务、挑战掌门 |
| `3` | 练功 | 消耗潜能练武、打坐、挂机修炼 |
| `4` | 打工 | 跑堂 / 趟子手 / 劈柴，赚取银两 |
| `5` | 集市 | 购买装备、上架摆摊 |
| `6` | 出城 | 四大区域野外遭遇战 |
| `7` | 擂台 | 与江湖众大侠切磋（每日 10 次） |
| `8` | 江湖 | 世界频道 / 门派频道 / 江湖快讯 |
| `9` | 排行 | 武功总等级榜 / 财富榜 / 声望榜 |

大厅底部命令行中直接输入数字回车，效果相同；输入 `help` 查看提示。

### 各页面要点

**创建角色**：四维各 10~30 随机，天赋总评四档——总分 ≥100「万中无一」、≥85「天资聪颖」、≥70「中人之姿」、其余「凡夫俗子」。只有 1 次重掷机会，总评 85+ 即可开局。

**属性页**：查看派生属性（命中/闪避/攻击/防御）；装备栏与背包（可穿戴、半价卖店）；使用金创药（气血 +50）、研读拳谱残页（随机已学武功修为 +100）；导出/导入 JSON 存档。

**拜师页**：左表为六大派及门槛，拜入后右侧显示师父传功列表（潜能 + 银两学习武功）、每日门派任务、挑战掌门、叛出师门。

**练功页**：`练一拳`（潜能 10 → 修为 50×(1+悟性%)）、`打坐`（免费，内功修为 +8）、`挂机修炼`（所选武功按真实时间累计修为，单次上限 30 分钟，切页不中断）。

**打工页**：选活计后挂机，10 秒一轮，单次上限 30 分钟，随时收工领钱。镖局可能遇袭（自动演算）。

**集市页**：「购买」页含系统商店与其他大侠的摊位；「我的摊位」页给背包装备定价上架（≥10 文），售出收 5% 手续费，其他大侠会来买走。世界频道吆喝可加快出手。

**出城页**：选择区域 → 随机遭遇 → 回合制文字战斗：`攻击` / 门派武功（耗内力，伤害更高）/ `轻功·闪避`（下回合闪避 ×1.8）/ `金创药` / `逃跑` / `自动演算到底`。战败仅损失 10% 银两，装备无损。

**擂台页**：挑战在线大侠立即自动演算；离线者可 `留言邀战`（1~3 分钟后自动应战）。切磋不损气血上限、不掉装备，胜者声望 +2。

**江湖页**：世界频道（Lv.3 起可发言）、门派频道（需拜师）、江湖快讯（全服事件播报）。

**排行页**：三榜每小时整点更新；登上榜首全服播报。

## 系统详解

### 四维属性与派生公式

| 属性 | 作用 |
|---|---|
| 膂力 | 攻击力（`攻击 = 膂力 + 武器攻`）；镖局打工门槛 |
| 身法 | 命中（`70 + 身法×0.8`）与闪避（`身法 + 轻功 − 2 + 鞋`）；华山门槛 |
| 悟性 | 练武收益（`+悟性%`）、挂机效率（`×(1+悟性/200)`）；武当/峨嵋门槛 |
| 根骨 | 气血（`12 + 根骨×6 + 内功×2`）、内力（`(根骨+内功)×2`）、防御（`根骨/3 + 防具`）；少林门槛 |

升级所需经验 `40 + 等级×30`；武功升级所需修为 `100 + 等级×30`（上限 100 级）。

### 六大门派与门派武功

| 门派 | 师父 | 拜师门槛 | 入门武学 | 进阶武学 | 高深武学 |
|---|---|---|---|---|---|
| 少林 | 玄苦大师 | 根骨 ≥ 18 | 少林长拳 | 罗汉拳（拳脚 30 级） | 拈花指（悟性 ≥ 25） |
| 武当 | 冲虚道长 | 悟性 ≥ 20 | 武当绵掌 | 太极剑（剑法 30 级） | 纯阳无极功（内功 35 级） |
| 华山 | 风清扬 | 身法 ≥ 18 | 华山剑法 | 狂风快剑（身法 ≥ 25） | 紫霞神功（内功 30 级） |
| 峨嵋 | 灭绝师太 | 悟性 ≥ 18 | 回风拂柳剑 | 飘雪穿云掌（拳脚 25 级） | 峨嵋九阳功（内功 30 级） |
| 丐帮 | 洪七公 | 不问出身 | 太祖长拳 | 打狗棒法（拳脚 35 级） | 降龙十八掌（声望 ≥ 100） |
| 魔教 | 东方不败 | 声望 ≥ 50（邪派） | 幽冥爪 | 摄魂大法（悟性 ≥ 22） | 葵花神功（内功 40 级） |

- 入门/进阶/高深武学消耗潜能与银两依次约为 **30/50 → 80~120/120~200 → 200~500/300~800**（潜能/文）。
- 同一时间只能拜一个门派；**叛门**：声望减半、门派武功尽数遗忘（需二次确认）。
- 每日福利：门派任务（潜能 +10 · 银两 +20 · 经验 +15）；门派武功 ≥ 50 级可**挑战掌门**（胜：声望 +50 · 经验 +200；负：无损失）。

### 打工（银两唯一稳定来源）

| 活计 | 门槛 | 收益 | 特点 |
|---|---|---|---|
| 客栈 · 跑堂 | 无 | 5 文/轮 | 稳定无风险 |
| 镖局 · 趟子手 | 膂力 ≥ 20 | 12 文/轮 | 每轮 12% 遇袭：战力够反赚 24 文，不够破财 20% |
| 柴房 · 劈柴 | 基本刀法 ≥ 10 | 8 文/轮 | 每轮额外刀法修为 +5 |

10 秒一轮、单次上限 30 分钟：满额跑堂约 **900 文**、趟子手约 **2160 文**、劈柴约 **1440 文 + 900 修为**。

### 野外历练（四区域）

| 区域 | 解锁 | 敌人（等级/气血） |
|---|---|---|
| 荒郊 | Lv.1 | 野狗（2/40）、流氓（3/60）、山贼（6/120） |
| 乱葬岗 | Lv.8 | 游魂（9/190）、僵尸（12/280） |
| 黑风寨 | Lv.15 | 山贼喽啰（14/340）、山贼头目（18/520） |
| 绝情谷 | Lv.25 | 银环蛇（24/640）、潭底鳄鱼（28/860） |

- 胜利奖励：`潜能 5+2×等级`、`银两 5+3×等级`、`经验 10+5×等级`；敌人等级 ≥ 自身−2 时额外声望 +1。
- 门派武功伤害约为普攻 1.3 倍且吃武功等级加成，耗内力 `8 + 等级/5`；5% 会心一击 ×1.5。
- 战败惩罚：昏迷回城（保留 30% 气血）、散落 10% 银两，**装备与属性无损**。

### 切磋、声望与称号

- 每日 10 次，自动演算，无损；胜者声望 +2、经验 20+对方武功总等级/2，败方也有经验 +10。
- 声望来源：切磋胜 +2 / 越级打野怪 +1 / 挑战掌门 +50。
- 称号阶梯：无名小卒(0) → 初入江湖(50) → 小有名气(200) → 声名鹊起(500) → 名动一方(1000) → 一代宗师(2000) → 天下第一(5000)。

### 集市经济

- 系统商店：生锈铁剑（攻+5/60 文）、粗布衣（防+2/30 文）、快靴（身法+3/90 文）、皮甲（防+5/120 文）、精钢刀（攻+12/320 文）、金创药（15 文）。
- 摆摊自定价（≥10 文），成交收 **5% 手续费**；定价不高于公允价（攻×25 / 防×20 / 身法×25+20）1.3 倍时更容易被大侠们买走。
- 背包装备可随时半价卖店回笼资金。

### 奇遇

| 奇遇 | 触发 | 效果 |
|---|---|---|
| 高人指点 | 练一拳时约 3% | 本次修为 ×2 |
| 心魔作祟 | 练一拳时约 1% | 本次修为减半 |
| 拳谱残页 | 打工时低概率 | 随身物品，研读后随机已学武功修为 +100 |

### 摸鱼保护机制

- `` ` `` 老板键：伪装 Excel 报表页 + 浏览器标签标题变为 `项目进度跟踪表_2026Q4_final_v3.xlsx`，`Esc` 或再按 `` ` `` 恢复。
- 挂机（练功/打工）单次上限 30 分钟，到点自动结算，**切换网页/最小化照常累计**。
- 非战斗状态下每 6 秒回 1 气血、每 15 秒回 1 内力，摸鱼回来血条自己就满了。
- 自动存档：事件驱动 + 每分钟一次落盘。

## 进阶攻略

### 新手第一天（0 → 站稳脚跟）

1. **掷骰**：总评 85+ 开局，70+ 也能玩（先天不足后天能补）。四维优先级：膂力（输出与打工）> 根骨（气血）≈ 悟性（成长）> 身法。
2. **先打野狗**：初始潜能 20 不够学武功（最便宜 30），去荒郊打 1~2 只野狗（潜能 +9/只），凑够 **30 潜能 + 50 文**（差钱先打两只流氓）。
3. **拜丐帮**：不问出身，太祖长拳无门槛——前中期最强开荒选择。追求后期上限可选少林（根骨流）或武当（悟性流）。
4. **跑堂攒钱**：挂 30 分钟跑堂 ≈ 900 文，买 **精钢刀（320 文）** 攻击 +12，输出质变；再补 **快靴（90 文）**。
5. **潜能别囤**：全部砸进太祖长拳/基本拳脚。等级 = 战斗力，`练一拳` 是主要消耗口，潜能见底就去打野。

### 中期发展（第 2~5 天）

- **打工升级**：膂力 ≥ 20 后立刻转 **镖局趟子手**（12 文/轮，遇袭基本打得过，等于白送钱），30 分钟满额 2000+ 文。
- **练功与挂机并行**：上班用 `挂机修炼`（收益 13 修为/分 × 悟性加成，30 分钟约 400+ 修为），午休/下班用 `练一拳` 清潜能。**打坐**在潜能耗尽时白嫖内功修为。
- **推图节奏**：基本拳脚 20 级 + 精钢刀可Farm荒郊；30 级去乱葬岗，45 级去黑风寨，60+ 级挑战绝情谷。打不过就 `轻功·闪避` 风筝或 `逃跑`（无惩罚）。
- **每日必做**：门派任务（+10 潜能）→ 10 次切磋（专挑「客栈跑堂甲」「摸鱼真难」等低武总等级的软柿子，约 +20 声望）→ 清空潜能。
- **经济第二曲线**：打到的多余装备上架摆摊，定价压到公允价 1.2 倍以内出货快；也可半价卖店保底。

### 后期目标

- **声望 50** → 可叛门转投魔教（先权衡：门派武功全忘 + 声望减半，建议在门派武功练满想换口味时再走）。
- **声望 100** → 丐帮弟子解锁 **降龙十八掌**（400 潜能/600 文），全游戏顶级输出。
- **门派武功 50 级** → 每日挑战掌门：胜则 +50 声望，是冲「名动一方」「一代宗师」称号的最快路径。
- **毕业目标**：武功总等级登顶群侠榜（榜首全服播报）→ 挑战掌门全胜 → 声望 2000「一代宗师」。

## FAQ

**Q：存档存在哪？会丢吗？**
A：浏览器 localStorage，按账号名隔离（支持多账号切换）。清浏览器缓存会丢档，请定期在属性页**导出存档**备份 JSON。换电脑用导入功能迁移。

**Q：关掉网页，挂机还算吗？**
A：算。挂机按真实时间结算，重进游戏自动补算（上限 30 分钟）。

**Q：战败有什么惩罚？**
A：仅损失随身 10% 银两，装备、属性、武功全部无损，气血回 30%——放心练级。

**Q：世界频道发不了言？**
A：需要角色等级 ≥ 3（防小号刷屏）；门派频道需先拜师。

**Q：其他"玩家"是谁？**
A：当前版本为本地模拟江湖（16 位风格各异的江湖大侠会聊天、摆摊、应战、随时间成长）。存档与联机均为本地实现，后续版本将接入云服务支持真实多人。

**Q：叛门后悔了怎么办？**
A：没有后悔药——声望减半、门派武功清零。叛门前确保想清楚（游戏内有二次确认）。

**Q：潜能上限是多少？**
A：无上限，但只有战斗、门派任务、切磋等行为产出，囤着不用是最大的浪费。

## 技术说明

- **架构**：纯原生 HTML/CSS/JavaScript 单文件（`index.html`，约 1650 行），零框架、零依赖、零构建。
- **存档**：localStorage，键名 `moyu_acct_<名号>`；`moyu_cur` 记录当前账号。
- **多人模拟**：16 位机器人玩家由本地时钟驱动（聊天灌水、快讯生成、摊位刷新、切磋应战），并随存档天数成长。
- **时间结算**：挂机收益基于 `Date.now()` 真实时间差计算，支持离线补算（30 分钟封顶）。
- **测试**：Playwright 自动化测试 57 项断言全通过（注册→创角→拜师→练功→打工→集市→战斗→切磋→频道→排行→老板键→存档恢复→重登）。

**部署到 GitHub Pages**：

```bash
# 1. 新建仓库（例如 moyu-jianghu），把本目录内容推上去
git init
git add .
git commit -m "feat: 摸鱼江湖 v1.0"
git branch -M main
git remote add origin https://github.com/<你的用户名>/moyu-jianghu.git
git push -u origin main
```

```text
# 2. 仓库 Settings → Pages
#    Source 选择 main 分支 / root（index.html 位于仓库根目录）
#    保存后访问 https://<你的用户名>.github.io/moyu-jianghu/
```

> 也可用任何静态托管（Vercel / Netlify / Cloudflare Pages）：直接上传 `index.html` 一个文件即可。
